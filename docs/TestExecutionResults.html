9. Execution Notes

Migration Highlights

  • VB.NET CInt → C# Convert.ToInt32: All integer conversions use banker's rounding (MidpointRounding.ToEven) to match original VB.NET behavior
  • Base64 passwords → BCrypt: Password hashing upgraded from insecure Base64 encoding to BCrypt with salt
  • OleDb/Access → EF Core/SQLite: Data access layer completely modernized with parameterized queries
  • Crystal Reports → QuestPDF: Report generation migrated to modern cross-platform PDF library
  • Excel Interop → ClosedXML: Excel export migrated to lightweight library without Office dependency
  • SQL Injection Prevention: All 20 SQL injection patterns tested and verified as blocked

  • WinForms UI layer is excluded from coverage (headless test environment)

  • Search/Filter (20): LIKE prefix match, filtering by multiple criteria
  • Security (20): SQL injection prevention (15 patterns) + BCrypt password hashing (5)
  • Reports (16): PDF generation (QuestPDF) + Excel export (ClosedXML) for all report types
